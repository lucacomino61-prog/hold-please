# Music for Hold FM

Drop tracks in this folder and list them in `manifest.json`:

```json
[{ "file": "lofi-hip-hop-loop.ogg", "title": "Lofi Hip Hop Loop", "by": "omfgdude", "license": "CC0" }]
```

Only CC0 / public-domain tracks go here (the manifest states the license). With an empty manifest the game plays its
own generated lo-fi loop.
